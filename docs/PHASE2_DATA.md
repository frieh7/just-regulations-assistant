# بيانات المرحلة الثانية — مساعد أنظمة وتعليمات JUST

كل الملفات مبنية من مكتبة واحدة للمقاطع (`clean/chunks.jsonl`) تُستخدم للـ CPT وللـ SFT ولاحقاً كمخزن RAG.

## الملفات

| الملف | الوصف | العدد |
|---|---|---|
| `clean/chunks.jsonl` | مكتبة المقاطع (مادة/فقرة من كل وثيقة) | 3,004 مقطع من 346 وثيقة |
| `cpt/train.jsonl` | نص خام للتدريب المسبق المستمر، وثيقة في كل سطر | 392 وثيقة، ~519 ألف كلمة |
| `cpt/heldout.jsonl` | وثائق محجوبة كاملة لقياس perplexity قبل/بعد | 44 وثيقة، ~34 ألف كلمة |
| `sft/facts.jsonl` | الحقائق (حقيقة = جواب واحد + 3 صيغ سؤال) | 2,958 حقيقة |
| `sft/train.jsonl` | أزواج المحادثة للتدريب | 7,986 زوج |
| `sft/val.jsonl` | أزواج التحقق (حقائق لا تظهر في train) | 888 زوج |
| `sft/checks_report.json` | نتائج الفحوص الآلية | — |
| `eval/seed_test_set_with_gold.csv` | الأسئلة الثلاثون الرسمية + `gold_chunk_ids` | 30 |

## تقسيم البيانات
- **CPT**: التقسيم على مستوى الوثيقة (90/10، seed=7). لا يوجد مقطع من وثيقة محجوبة في التدريب.
- **SFT**: التقسيم على مستوى `fact_id` (90/10، seed=42، طبقي حسب `source_group`). الصيغ الثلاث لنفس الحقيقة دائماً في نفس القسم.
- **الاختبار**: الأسئلة الثلاثون في `eval/` فقط، ولا تدخل في أي تدريب.

## حقول `sft/train.jsonl` و `val.jsonl`
- `id`: `{fact_id}-{msa_1|msa_2|jo}`
- `fact_id`, `doc_id`, `chunk_ids` (المقاطع الداعمة — تصلح كـ gold للاسترجاع)
- `type`: number / rule / definition / procedure / prereq / plan_hours / refusal / out_of_scope ...
- `source_group`: `regulation` (2,289 حقيقة) / `plan` (623) / `refusal` (46)
- `audience`: `bachelor` / `graduate` / `student`
- `style`: `msa` (صيغتان) أو `jo` (صيغة بالعامية الأردنية)
- `verified_from`: `text` (من النص المستخرج) / `image` (قُرئت من صورة الصفحة لأن النص المستخرج معطوب) / `structured` (الخطط)
- `messages`: `[system, user, assistant]` — الجواب ينتهي دائماً بـ «المصدر: اسم الوثيقة، المادة».

## الفحوص التي أُجريت
1. **تسريب الاختبار**: تطابق تام أو تشابه 4-gram ≥ 0.5 مع أي من الأسئلة الثلاثين ← 4 صيغ أُعيدت صياغتها، والنتيجة الآن 0.
2. **تكرار الأسئلة** ← الفحص الأخير وجد 64 سؤالاً مكرراً بين حقائق مختلفة؛ أُعيدت صياغتها كلها بذكر المستوى الدراسي/البرنامج أو بتخصيصها للحقيقة، والنتيجة الآن 0 مكرر و0 تسريب و0 أرقام غير موجودة في النص (8,874 زوج).
3. **الأرقام**: كل رقم في جواب مصدره `text` موجود في نص الوثيقة (0 مخالفات). الحقائق من نوع `image` (1,298) لم تُفحص آلياً لأن نصها المستخرج غير موثوق؛ تحتاج مراجعة بشرية بالعينة.
4. **ربط المقاطع**: 2,127 ربط قوي، 134 متوسط، 28 ضعيف (`link_score < 0.3` في `facts.jsonl`) — الضعيفة تُراجع يدوياً قبل استخدامها كـ gold للاسترجاع.

## حدود معروفة (تُسجَّل في سجل القرارات)
- `gold_chunk_ids` لأسئلة الاختبار رُبطت آلياً (BM25 + رقم المادة) وتحتاج تأكيداً بشرياً.
- وثائق فيها نسخ متعارضة عبر الزمن (تأمينات السكن 10/50 ديناراً، جداول التوفل، ساعات التجسير 45/55). اعتُمد الأحدث حيث أمكن.
- أسئلة SFT تغطي الطالب (بكالوريوس + دراسات عليا مع ذكر المستوى صراحة). أسئلة الموظفين مؤجلة للمرحلة 3، لكن نصوصها داخل CPT.
- 0286 (قرارات دراسات عليا قديمة) و0238: أُخذ منهما فقط ما لا يتعلق برسوم قديمة.
- حقائق الخطط مولّدة بقوالب من بيانات منظمة (8 حقائق لكل خطة × 78 خطة)، فتنوعها اللغوي أقل من حقائق التعليمات.
